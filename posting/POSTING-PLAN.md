# Plan: posting all of Jason's research to the SolidCraft team

Prepared 2 November 2026. Target repository: [tangency-labs/solidcraft](https://github.com/tangency-labs/solidcraft).

## How it works

- **16 posts over 7 posting days, at most 3 a day.** Foundations first, related files grouped into one comment, so #1621 gets 8 more comments instead of 14.
- **Every text box is a plain file.** Open the "Text to paste" link, select all, copy, and paste it into GitHub. Click **Preview** before posting; the bold, bullets and links should all show.
- **Every file to attach is current.** Each has the "Export control, sanctions and government use" section and the team rules. Leftover "[TODO Jason]" prompts were taken out of these copies, so nothing looks unfinished. Download from the "Attach" link (Save As, keep the file name), or take the same file from the project's `posting-plan/attach/` folder, then drag it into the GitHub comment box.
- **A comment:** open the issue, scroll to the bottom, paste, attach, Preview, **Comment**.
- **A new issue:** **New issue**, choose **Feature request**, paste the title, paste box 1 into "What are you trying to do" and box 2 into "How you imagine it working", attach the file at the end of box 2, Preview, **Create**.
- **After each post,** tick it here or send me the link and I'll record it.

## Pacing rules

- If a maintainer replies, answer (or ask me to draft the answer) before posting the next item on that issue.
- If anyone asks you to slow down, post elsewhere, or combine comments, stop and tell me; I'll rework the rest.
- Skip weekends; nothing here is urgent.
